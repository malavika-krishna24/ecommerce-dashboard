# Brazilian E-Commerce Analytics Dashboard

An interactive Business Intelligence dashboard developed
using Python, Streamlit, Hadoop, HDFS and Apache Hive.

## Features
- Sales and revenue analysis
- Monthly order trends
- Product and seller performance
- Payment method analysis
- Customer review analysis
- Freight and delivery analytics
- Interactive filters and downloadable reports

## Technologies
- Python
- Apache Hadoop
- HDFS
- Apache Hive
- Pandas
- Streamlit

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
